# Experiments

Put local prototypes here.

Suggested pattern:

- one folder per experiment
- name folders with a date prefix, for example `2026-03-28-chat-shrinkwrap`
- give each experiment a short `README.md` with:
  - goal
  - commands
  - fonts and browser assumptions
  - findings
  - whether the idea belongs upstream or should stay local

General rule:

- keep `../upstream/chenglou-pretext` as the clean reference
- copy or import from upstream when needed
- avoid editing upstream directly unless the work is intentionally becoming an upstream-style patch
